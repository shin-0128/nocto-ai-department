# Nocto AI Department（AIデパート）

中小企業（まず地方の建築・建設）に **「AI社員（エージェント）」を月額 + 初期導入費で配備** する事業。
SaaS でも 人間BPO でもない第3の売り方＝「設定済みのAI社員を配属し、運用まで持つ（done-for-you）」。

## 中身（成果物）

| ファイル | 役割 |
|---|---|
| [`diagnose/ai-shain-jitsuen.html`](diagnose/ai-shain-jitsuen.html) | **見える化の実演デモ＝営業の入口**。写真投入→AIの処理を丸見えで実況→工種別に自動整理→「確認して承認だけ」→効果可視化→診断へ導線。AI社員キャラ「事務のジロー」。 |
| [`diagnose/ai-agent-diagnosis.html`](diagnose/ai-agent-diagnosis.html) | 導入診断ツール。業態別（建築総合/リフォーム/設備/監督/土木/飲食/汎用）に業務棚卸し→AI社員を自動当て込み→回収月数を試算→A4印刷（助成金申請の根拠資料にも）。 |

両方とも **単一HTML・完全オフライン（外部参照ゼロ）・iPad/PC どちらでも**。ダブルクリックで開くだけ。

## 使い方（面談）

1. `ai-shain-jitsuen.html` を開いて「写真を投入する」→ AIが裏で何をしているか見せる（入口）。
2. 最後のCTAから `ai-agent-diagnosis.html` へ → その場で業務を選び回収月数を出す。
3. 診断のStep4を印刷 → A4サマリーをそのまま置いて帰る。

## 価格・数値は全部「仮」

各HTMLの `CONFIG` オブジェクトに集約。確定したらそこだけ書き換えれば全画面に反映される。
